# Background Explorer Examples

## Overview
This directory contains example scripts to populate bgexplorer models.

### qis
A full background model for a superconducting chip in a dilution refrigerator,
based on ["Abatement of ionizing radiation for superconduting quantum devices"](https://dx.doi.org/10.1088/1748-0221/19/09/P09001).
Contains a full assembly hierarchy, assays, and hit efficiencies.

### root_to_hiteff
An example script showing how to create a HitEfficiency from a ROOT TChain.
